1 質數 Prime numbers 2 marks

Which of the following number is NOT a prime number?

下列哪一個數 不是 質數？

A. 59
B. 69 ✓
C. 79
D. 89

題眼 Key words

  • prime number 質數 = 只有 1 和它自己兩個因數的自然數（>1）
  • NOT ＝ 找「例外」，畫圈提醒自己

解法 Working

69 = 3 × 23 → 有第三個因數 → 合數 (composite) 59, 79, 89 → 用 2,3,5,7 都除不盡 → 質數

英文怎麼讀

「Which of the following number is not a prime number?」中 of the following = 以下這些之中； which ... is not = 哪一個不是。答題時把四個選項都「過一遍」，不要看到 59 覺得是質數就馬上選 A。
2 因數 Factors / 整除性 Divisibility 2 marks

Which of the following are factors of 64 890?

下列哪些是 64 890 的因數？

I. 3     II. 6     III. 8
A. I and II only ✓
B. I and III only
C. II and III only
D. I, II and III

題眼 Key words

  • factor 因數：能整除它的數
  • only ＝ 只有這些，考細心

解法 Working（用整除性檢定）

I. 3 → 數字和 6+4+8+9+0 = 27，可被 3 整除 → YES II. 6 → 要同時可被 2 和 3 整除：末位 0（偶數）✓，數字和 27 ✓ → YES III.8 → 看末三位 890：890 ÷ 8 = 111.25 ✗ → NO

必背整除性檢定 Divisibility tests

  • 2：末位 0,2,4,6,8  |  5：末位 0 或 5  |  10：末位 0
  • 3：各位數字和可被 3 整除  |  9：各位數字和可被 9 整除
  • 4：末兩位可被 4 整除  |  8：末三位可被 8 整除
3 H.C.F. 最大公因數 2 marks

The H.C.F. of 3³ × 7⁴ × 11² and 7³ × 11³ is

求 3³×7⁴×11² 與 7³×11³ 的最大公因數。

A. 7³ × 11² ✓
B. 7⁴ × 11³
C. 3³ × 7⁴ × 11³
D. 3³ × 7⁷ × 11⁵

解法 Working

H.C.F. → 取「共同的質因數」，指數取 小 的那個 共同質因數：7 和 11（3 只在第一個出現 → 不要） 7 ：取 min(4,3) = 3 11：取 min(2,3) = 2 H.C.F. = 7³ × 11²

口訣 Formula

  • H.C.F. = 共同質因數，指數取 小（min）
  • L.C.M. = 所有質因數，指數取 大（max）

記法：HCF 要「共同」，所以挑剔、取小的；LCM 要「包住全部」，所以大方、取大的。

求 48、60、72 的最小公倍數。

A. 12
B. 24
C. 720 ✓
D. 1440

解法 Working

48 = 2⁴ × 3 60 = 2² × 3 × 5 72 = 2³ × 3² L.C.M. = 2⁴ × 3² × 5 = 16 × 9 × 5 = 720

5 四則運算次序 Order of operations 2 marks

6 − {1 + [15 − (3 + 4) × 2] × 3} =

計算 6 − {1 + [15 − (3 + 4) × 2] × 3}。

A. 0
B. 2 ✓
C. 8
D. 41

解法 Working（由內到外）

6 − {1 + [15 − (3 + 4) × 2] × 3} = 6 − {1 + [15 − 7 × 2] × 3} ← 先乘除：7×2 = 14 = 6 − {1 + [15 − 14] × 3} ← 方括號 = 6 − {1 + 1 × 3} = 6 − {4} = 2

英文括號名稱 Bracket names

  • ( ) round brackets / parentheses 圓括號
  • [ ] square brackets 方括號
  • { } curly brackets / braces 大括號
  • 次序：由最內層做起 → 先 × ÷ 後 + −（同級由左至右）
6 有向數 Directed numbers 2 marks

[(−5) − (−3) + 2] × (−1) =

計算 [(−5) − (−3) + 2] × (−1)。

A. 1
B. 0 ✓
C. −1
D. −10

解法 Working

[(−5) − (−3) + 2] × (−1) = [ −5 + 3 + 2 ] × (−1) ← 減負數 = 加正數 = [ 0 ] × (−1) = 0 ← 0 乘任何數都是 0

關鍵規則 Rules

  • a − (−b) = a + b（減負 = 加正）
  • a + (−b) = a − b
  • 0 × 任何數 = 0（不是 −1，也不是 1）
7 帶分數 ÷ 帶分數 2 marks

(−13¾) ÷ (−1⅚) =

計算 (−13 又 3/4) ÷ (−1 又 5/6)。

A. 15/2 ✓
B. 13 又 9/20
C. −15/2
D. −13 又 9/20

解法 Working

第 1 步：帶分數 → 假分數 −13¾ = −(13×4 + 3)/4 = −55/4 −1⅚ = −(1×6 + 5)/6 = −11/6 第 2 步：除以分數 = 乘以它的倒數 (multiply by the reciprocal) (−55/4) ÷ (−11/6) = (−55/4) × (−6/11) 第 3 步：負負得正，約分 = (55 × 6) / (4 × 11) = (5 × 6) / 4 ← 55 ÷ 11 = 5 = 30/4 = 15/2

必記 Rules

  • mixed number 帶分數 → improper fraction 假分數：a b/c = (a·c + b)/c
  • reciprocal 倒數：11/6 → 6/11
  • 兩數同號相除 → 結果為正（負 ÷ 負 = 正）
8 數線上的大小關係 2 marks 高難度

Referring to the following number line, which of the following MUST be true?

參考下面的數線，下列哪一項必然成立？

數線上由左至右依次是 a、b、0、c，即 a < b < 0 < c。

A. a + b > 0
B. a − b > 0
C. b − a > c
D. a + b < c ✓

解法 Working（用「正負」判斷，不必知道具體數字）

已知：a、b 都是負數，c 是正數。 A. a + b > 0 → 負 + 負 = 負，不可能 > 0 ✗ B. a − b > 0 → 因 a < b，所以 a − b < 0 ✗ C. b − a > c → b − a 是正數，但可能只有 0.05，而 c 可能很大 → 不一定 ✗ D. a + b < c → 左邊是負數，右邊是正數，負 < 正 永遠成立 ✓

MUST be true 的解題法

這類題不能靠「代入一組數」，要找「無論如何都成立」的那一項。
技巧：用極端值反駁（想讓它錯，能不能找到例子？找得到就不可能「必然」成立）。
例如 C：取 a = −0.1, b = −0.05, c = 100，則 b − a = 0.05 < 100 → C 就錯了。

17 代數式化簡（判斷對錯） 2 marks

Which of the following is / are correct?

下列哪些算式正確？

I. 6x + 7 − 8x = 7 − 2x II. 4x − 3 − (x − 2x) = 5x − 3 III. −5x ÷ 2 × 4x = −5/8
A. I only
B. III only
C. I and II only ✓
D. II and III only

解法 Working

I. 6x + 7 − 8x = (6x − 8x) + 7 = −2x + 7 = 7 − 2x ✓ 正確 II. 4x − 3 − (x − 2x) = 4x − 3 − (−x) = 4x − 3 + x = 5x − 3 ✓ 正確 III. −5x ÷ 2 × 4x ← 乘除同級，由左至右 = (−5x ÷ 2) × 4x = (−2.5x) × 4x = −10x² ✗ 不是 −5/8

  • 同類項才能合併：6x 和 −8x 都是 x 項 → 可以合；7 是常數項 → 單獨留下。
  • 減號後面有括號：−(x − 2x) 要整個括號變號 → −x + 2x。
  • ÷ 和 × 同級，由左至右 → 「先除 2，再乘 4x」，不是「先算 2 × 4x」。

18 質因數分解求 L.C.M. 0–1 / 6 失分

Find the L.C.M. of 30, 45 and 56 by prime factorization.

用質因數分解法求 30、45、56 的最小公倍數。

標準解法 Model answer

30 = 2 × 3 × 5 45 = 3² × 5 56 = 2³ × 7 L.C.M. = 2³ × 3² × 5 × 7 = 8 × 9 × 5 × 7 = 2520

你的卷面 Your work

30 = 2×3×5×1 45 = 2×3×5 ← 45 是奇數，不可能有 2！ 56 = 2×28 ← 28 不是質數 L.C.M. = 2×3³×5×1×28 = 1680

你後來在下面補寫的 45 = 3²×5、56 = 2³×7、L.C.M. = 2³×3²×5×7 = 2520 完全正確，但寫在指定作答區之外，沒有計分。

錯在哪 · 三個致命細節

  • ① 45 = 2 × 3 × 5 是絕對不可能的：45 是奇數（odd），奇數不可能被 2 整除。當你寫出「偶數因子」給一個奇數，就代表這一步算錯了。檢查方法：乘回去 2×3×5 = 30 ≠ 45。
  • ② 56 = 2 × 28 沒有分解完：28 不是質數，要繼續分 → 28 = 2×2×7 → 56 = 2³×7。質因數分解的結果只能是質數相乘。
  • ③ 不要寫 ×1：30 = 2×3×5 就已經完整，加 ×1 在數學上不算錯，但在考試中會被視為「未完成／不規範」而扣分。

L.C.M. 的算法（與 H.C.F. 對比）

H.C.F. = 取共同質因數，指數取小 L.C.M. = 取全部質因數（含只出現一次的），指數取大 本例質因數有 2、3、5、7 2：最大指數 3（來自 56） → 2³ 3：最大指數 2（來自 45） → 3² 5：最大指數 1（來自 30、45）→ 5 7：最大指數 1（來自 56） → 7 L.C.M. = 2³ × 3² × 5 × 7

19 指數記法 Index notation 0 / 4 失分

Evaluate 5³ − 10² − 2⁴ and express the answer in index notation.

計算 5³ − 10² − 2⁴，並用指數記法表示答案。

標準解法 Model answer

5³ = 5 × 5 × 5 = 125 10² = 10 × 10 = 100 2⁴ = 2 × 2 × 2 × 2 = 16 5³ − 10² − 2⁴ = 125 − 100 − 16 = 9 = 3²

你的卷面 Your work

5³ = 75 ← 應該是 125 10² = 100 ✓ 2⁴ = 32 ← 應該是 16 = −57 ✗

下面補寫的 125 − 100 − 16 = 9 = 3² 完全正確，但沒有計分。

錯在哪 · 指數到底是甚麼

01

答案寫在指定位置

每一題都有指定的橫線／方格。答案只能寫在那裡。草稿寫在頁邊空白處並用線隔開，或寫在草稿紙上。

02

一題只寫一個最終答案

寫錯了不要緊，用一條線劃掉，然後在答案線上重寫。不要讓兩個答案同時出現在卷面上——老師只會看最明顯的那個。

題目問甚麼，就答甚麼

額外建議 · Beyond the Paper

除了補數學，這幾件事會讓你「一年後的自己」感謝現在的自己。

① 建立錯題本 · The error notebook（最重要）

買一本 A4 橫線筆記，每頁只放 1 題，分成三欄：

① 原題 + 我的錯② 為甚麼錯（一句話）③ 正確做法 + 新學的表達
5³ − 10² − 2⁴
 把 5³ 當成 5×15，以為指數是乘。
125 − 100 − 16 = 9 = 3² index notation = 指數記法

用法：每週日把當週的錯題本重看一次，遮住第 ③ 欄重做。做對就打一個紅勾，連對兩次可以「畢業」（撕掉那頁）。

② 每日 60 秒「數學心算」

每天早上花 60 秒，出聲唸出： 2¹=2 2²=4 2³=8 2⁴=16 2⁵=32 2⁶=64 2⁷=128 2⁸=256 3²=9 3³=27 3⁴=81 4²=16 4³=64 5³=125 7×8=56 9×9=81 12×12=144 15×15=225

這份卷子裡 5³、2⁴、45 的分解、1500÷15 全部是「基本事實」型的錯誤。心算熟了，這些分數自動拿回來。

③ 用「費曼法」講題 · Explain it out loud

每週挑 1 題，用手機錄音，用中英混合講 60 秒：
「這題在問 find the L.C.M.，所以我要先做 prime factorization…… 45 是奇數，所以不可能有因數 2，我這裡錯了……最後答案是 2520。」

為甚麼有效：講得出來 = 真的懂。講到卡住的地方，就是你還沒懂的地方。順便練了英文表達。

④ 一頁紙公式卡 · One-page formula card

把第 ⑤ 節的「速查卡」抄成一張 A5 卡，貼在書桌前。不要抄在 iPad 裡——手抄的過程本身就是記憶。
內容只放：指數表、整除性、HCF/LCM 口訣、次方符號規律、等差項數公式、10 個英文句型。
